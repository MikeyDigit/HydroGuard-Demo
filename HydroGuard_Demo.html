Calibration reminders
pH sensor — calibrate before each session
Use pH 4.0, 7.0, and 10.0 buffer solutions. Two-point minimum. Rinse probe with DI water between buffers. pH sensors drift — especially below pH 5. Store probe in 3M KCl storage solution.
Turbidity — weekly verification
Zero-calibrate in clean DI water. Verify with 100 NTU formazin reference if available. Wipe sensor lens with soft cloth. Avoid air bubbles in the measurement chamber.
TDS — calibrate with 342 ppm NaCl standard
Make 0.5g NaCl in 1L DI water = ~1000 ppm. Dilute 1:3 for 342 ppm standard. Adjust K constant in code until sensor reads within 5%.
Project overview
HydroGuard is a bench-scale smart water filtration and quality monitoring platform built as an engineering portfolio project. It integrates a physical multi-stage gravity filtration unit, a microcontroller-based sensor array, Python data logging, a rule-based AI recommendation engine, and this professional live web dashboard.
Connection to water infrastructure
This project demonstrates the workflow used by environmental and water engineering consultants to evaluate treatment performance, collect field data, log results, and communicate findings to clients and regulators. The skills involved — sensor integration, data analysis, treatment efficiency calculations, dashboard communication, and AI-assisted anomaly detection — are directly applicable to water infrastructure work at firms like Stantec, WSP, AECOM, Hatch, and Jacobs.
Safety disclaimer (important)
HydroGuard is a prototype monitoring and demonstration system only. Output water must not be consumed. The system is not a certified water treatment device. Cheap analog sensors are not laboratory-grade instruments. pH sensors drift over time. TDS is not equivalent to water safety. Sand and activated carbon do not remove all contaminants, dissolved metals, pathogens, or pharmaceuticals. The value of this project lies in demonstrating systems integration, monitoring concepts, data analysis, and engineering communication — not in producing potable water.
Honest limitations
Analog sensors (turbidity, pH, TDS) have ±5–15% accuracy and require regular calibration. Results should be treated as indicative, not laboratory-certified.
The ESP32 ADC is non-linear near rail voltages. Readings at 0V and 3.3V extremes are unreliable. All sensor conditioning boards should be verified for output voltage range compatibility.
Sand and activated carbon filtration effectively reduces turbidity and some adsorbed compounds. It does not reliably remove dissolved nitrates, heavy metals, fluoride, microorganisms, or pharmaceutical residues.
This dashboard is running in demo mode. Simulated data is designed to be realistic but does not represent actual sensor measurements. Connect the ESP32 and Python data logger for real readings.
